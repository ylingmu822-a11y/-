# 下書きについてのメモ

設計図（「設計図と史料出典表」）に沿って、序論から結論までの下書きを作った。

## ファイル

- `本文_下書き.md` / `.docx`：本文と註
  - 史料の本文は本文に入れず、【史料①】の形で示した。
  - 註は規定の順（編著者名、「論文名」、『書名』、頁、発行所、発行年）で書いた。同じ文献の2回目以降は「○○前掲註（○）」とした。
- `史料集.md` / `.docx`：本文の【史料①〜⑲】に対応する史料集。原典、取った本と頁、照合の状態を付けた。
- `src_*.md` と `build.py`：下書きの元ファイルと組み立て用のスクリプト。
  - `src_body1.md`・`src_body2.md` を直してから `python3 build.py` を実行すると、註の番号と前掲註、史料の番号が振り直される。

## 桃崎論文を確認して直したこと（第2版）

桃崎有一郎「建武政権論」（印刷43〜74頁、PDFの頁+41＝印刷頁）を画像で確認し、下書きで引いた頁をすべて照合した。

- **基準の出典を直した**：基準①②は、桃崎48頁（由緒の次元を超越する天皇の意思）と53頁（否定したのは相伝自体ではなく「相伝・由緒の自立性」）をほぼ言い直したものだった。序論でそのことを明記し、本稿の課題を「この理念が政策でどこまで貫かれ、どこで修正されたかを確かめること」とした。
- **誤りを直した**：
  - 44頁：桃崎は倒幕の目的を「皇位継承者を専断する幕府の排除という一点に尽きる」とする。下書きの「名分だけに求めない」は誤りだった。
  - 56頁の笠置の安堵は「非敵認定」で、本質は抽象的な安堵である。
- **反対説として正面から扱った**：
  - 桃崎は、七月令を「天皇至上主義の後退を意味しない」とし（57頁）、国宣を安堵権の委譲ではなく「事務の転嫁」とする（58頁）。
  - 本稿は「理念の水準では後退していないが、手続きの水準では基準①がいったん後退し、のちに回復した」と位置づけた。
  - さらに、その回復が桃崎の言う「法治の崩壊」（60頁）と表裏だった、と第三章・結論に書き足した。
- **事書条々の年代**：桃崎は①を建武二年二月の訴訟法、②を建武元年十月と建武二年二月の立法とする（58・60頁）。近藤（建武元年三月頃）とは食い違う。本文では近藤に従い、食い違いを明記した。桃崎の典拠となる註は【要確認】。
- **新しく使った頁**：

  - 59頁（決断所＝天皇が保証するシステム、訴状の殺到）：第三・四章
  - 58頁（徳政令）：第四章

## 設計図で「あなたが決める」とされていた点（下書きでの仮の選択）

1. **問い一の答え**：基準②は一貫した。基準①は七月にいったん後退し、決断所と事書条々を通じて回復した。序論の見通し、第三章の結論、結論をこの一文に揃えた。
2. **「原則として」の扱い**：例外を設けるかどうかを天皇が決めている場合も、基準の内とした（序論三）。
3. **呼び方の統一**：「第一・第二の要素」はやめて、すべて「基準①②」とした。
4. **酒鑪役の「先規」**：天皇が回復を命じているので、基準の内とした。
5. **徳政令**：建武元年五月三日の徳政令は「天皇の許しのもとでの例外」と判定した。網野が推定する元亨期の徳政令は別のものとして扱い、判定を保留した。
6. **護良と後醍醐の対比**：どちらも「本領の知行と恩賞の約束」という同じ形で安堵を出していたが、護良の令旨は天皇の許しを経ていない。この点を違いとした（近藤の史料Ⅰ）。
7. **近藤の「政権の安定化に伴う抑制」**：序論の研究史に一文足し、第四章で詳しく扱った。
8. **鎌倉幕府も旧領回復を抑制していた点**：結論で、後醍醐の独自性を基準②ではなく基準①に置いた。
9. **日付**
   - 七月官宣旨は二十五日とした（近藤）。
   - 鎌倉陥落は五月二十二日とした（丸谷は二十一日）。
   - 米価公定令は「五月〜六月」とぼかした。
   - 花園天皇宸記は元亨四年九月十九日条裏書に統一した。
10. **事書条々②**：近藤238頁の画像で本文を確認したので、第三章第四節に入れた。
11. **第五章**：第三節（建武式目）を残した。後代の評価（太平記「雲景未来記」）との比較を第四節として加えた。
